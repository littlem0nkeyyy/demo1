# Machina presentation

Mở [`machina-presentation.html`](machina-presentation.html) bằng trình duyệt, nhấn `F11` để toàn màn hình và dùng phím `←` / `→` để chuyển slide.

English version: mở [`machina-presentation-en.html`](machina-presentation-en.html).

Deck gồm 12 slide (1 slide mở đầu + 11 nội dung), bản tiếng Việt:

1. Machina — Product Intelligence Gateway
2. Bài toán: AI shopping cần tính kiểm chứng và quyền kiểm soát
3. Giải pháp: gateway giữa buyer agent và merchant catalogue
4. Kiến trúc hai mặt: dashboard và MCP server
5. Luồng tìm kiếm end-to-end
6. Ranking: verified match trước, utility sau
7. CONTROL và ba visibility tiers
8. Demo scenario: một yêu cầu, ba merchant
9. Evidence và bốn MCP tools
10. Merchant intelligence loop
11. Validation, giới hạn hiện tại và kết luận

Lưu ý: toàn bộ merchant, sản phẩm, giá, review và ảnh trong repo là dữ liệu synthetic phục vụ demo/testing.
